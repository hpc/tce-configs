# Running tests

These tests are run by CI, but you can run them yourself.

You'll need:

 - A reasonably up to date version of shellcheck
 - The python pylint package.

## At LANL
On LANL clusters, you can simply activate the python environment
at `/usr/projects/hpctools/spack-configs-env/`:

```bash
source /usr/projects/hpctools/spack-configs-env/bin/activate
```
